# Ficha del Cliente: Tienda Deportiva

## 1. Tipo de tienda
Comercializador minorista de artículos deportivos (calzado, ropa, accesorios y equipos de entrenamiento).

## 2. Necesidad que resuelve
El sistema automatiza el control del inventario de artículos deportivos, permite una facturación rápida de múltiples productos y alerta al administrador cuando las existencias están bajas.

## 3. Usuarios del sistema
- **Administrador:** Registra productos nuevos, revisa inventario y ve reportes.
- **Cajero:** Registra las ventas diarias.

## 4. Historias de Usuario
1. **HU01:** Como administrador, quiero registrar nuevos artículos deportivos (código, nombre, precio, stock y tipo) para mantener actualizado el inventario.
2. **HU02:** Como administrador o cajero, quiero consultar la lista de productos disponibles con su precio y stock actual.
3. **HU03:** Como cajero, quiero registrar una venta que incluya varios productos y cantidades para facturar al cliente.
4. **HU04:** Como cajero, quiero que el sistema calcule automáticamente los impuestos o descuentos en la venta.
5. **HU05:** Como administrador, quiero que el sistema me alerte si el stock de un producto queda por debajo del mínimo.
6. **HU06:** Como administrador, quiero ver un reporte con el total de las ventas realizadas.
